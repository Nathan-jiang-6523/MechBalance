# P1 材料力学 MVP 用户验收算例填写表

## 填写规则

- 本文件只登记用户提供的验收真值；不引用参考书、PDF 或开发实现结果。
- 每个算例请填写完整输入、单位、预期结果、符号方向和容差。暂不能确认时保留 `待确认`，不要猜值。
- `容差`请分别写数值结果、位置结果；可用绝对误差、相对误差或两者组合。
- `填写状态`建议使用：`未填写`、`填写中`、`待复核`、`已确认`、`不采用`。
- 方向描述应使用项目统一坐标与正负号；有跳变时分别填写左值 `x-`、右值 `x+`。
- 单位默认优先采用 `t–mm–s–N–MPa`，也可指定其他合法单位。

## A. 四种截面性质

### [x] SEC-RECT-01：矩形截面正常算例

- **ID**：`SEC-RECT-01`
- **目的**：验证矩形截面的面积、形心、惯性矩、截面模量、极惯性矩及扭转常数。
- **输入及单位**：宽度 `b = 80 mm`；高度 `h = 120 mm`。
- **预期输出及单位**：`A = 9600 mm²`；形心 `(x̄, ȳ) = (0, 0) mm`；`Ix = 11520000 mm⁴`；`Iy = 5120000 mm⁴`；`Ixy = 0 mm⁴`；`Wx+/Wx-/Wy+/Wy- = 192000/192000/128000/128000 mm³`；`Jp = 16640000 mm⁴`；`Jt = 12018641.6461 mm⁴`。
- **符号方向**：原点在截面几何中心（与形心重合）；`x` 向右、`y` 向上；外边界为 `x = ±40 mm`、`y = ±60 mm`；`Ix/Iy` 为过原点的形心轴。
- **容差**：数值相对误差 `≤ 1×10⁻⁶`；形心绝对误差 `≤ 1×10⁻⁶ mm`。
- **边界/备注**：`Jp = Ix + Iy`；`Jt` 采用矩形 Saint-Venant 工程近似式（短边/长边 `= 2/3`），不是 `Jp`。
- **填写状态**：已确认（三轮复算）。

### [x] SEC-RECT-02：矩形截面非法几何

- **ID**：`SEC-RECT-02`
- **目的**：验证零值、负值或缺失尺寸不会进入计算。
- **输入及单位**：`b = 0 mm`；`h = 120 mm`。

- **容差**：不适用；仅当校验失败、结果区不产生数值时通过。

- **填写状态**：已确认（三轮复核）。

### [x] SEC-HRECT-01：空心矩形截面正常算例

- **ID**：`SEC-HRECT-01`
- **目的**：验证空心矩形截面性质及内外尺寸约束。
- **输入及单位**：外宽 `B = 100 mm`；外高 `H = 140 mm`；内宽 `b = 80 mm`；内高 `h = 120 mm`。
- **预期输出及单位**：`A = 4400 mm²`；形心 `(x̄, ȳ) = (0, 0) mm`；`Ix = 11346666.6667 mm⁴`；`Iy = 6546666.6667 mm⁴`；`Ixy = 0 mm⁴`；`Wx+/Wx-/Wy+/Wy- = 162095.2381/162095.2381/130933.3333/130933.3333 mm³`；`Jp = 17893333.3333 mm⁴`；`Jt = 12444545.4545 mm⁴`。
- **符号方向**：原点在截面几何中心（与形心重合）；`x` 向右、`y` 向上；外边界为 `x = ±50 mm`、`y = ±70 mm`，内边界为 `x = ±40 mm`、`y = ±60 mm`；内孔同心。
- **容差**：数值相对误差 `≤ 1×10⁻⁶`；形心绝对误差 `≤ 1×10⁻⁶ mm`。
- **边界/备注**：四壁等厚 `t = 10 mm`；`Jt = 4A_m²/∮(ds/t)`，按中线尺寸 `90 mm × 130 mm` 的薄壁闭口近似；不得与精确弹性解或 `Jp` 混用。
- **填写状态**：已确认（三轮复算）。

## B. 简支梁

### [x] BEAM-SS-P-01：任意位置集中力

- **ID**：`BEAM-SS-P-01`
- **目的**：验证简支梁集中力工况的反力、场值、跳变、极值及曲线。
- **输入及单位**：`L = 1000 mm`；`E = 200000 MPa`；矩形截面 `96 mm × 100 mm`，`I = 8000000 mm⁴`；向下集中力 `P = 10000 N`；`a = 400 mm`。
- **预期输出及单位**：`RA = 6000 N`、`RB = 4000 N`；`x=0+`：`V/M/θ/v = 6000 N / 0 N·mm / -4.000000×10⁻⁴ rad / 0 mm`；`x=400`：`M=2400000 N·mm`、`θ=-1.000000×10⁻⁴ rad`、`v=-0.120000 mm`，`V(a-)=6000 N`、`V(a+)=-4000 N`；`x=1000-`：`V/M/θ/v=-4000 N / 0 N·mm / 3.500000×10⁻⁴ rad / 0 mm`。`Vmax=6000 N`（`0<x<400`），`Vmin=-4000 N`（`400<x<1000`）；`Mmax=2400000 N·mm @ x=400 mm`、`Mmin=0 @ x=0,1000 mm`；`θmin=-4.0×10⁻⁴ rad @ x=0`、`θmax=3.5×10⁻⁴ rad @ x=1000`；`vmin=-0.1234683945 mm @ x=470.849738 mm`、`vmax=0 @ x=0,1000 mm`。本例不验收应力。
- **符号方向**：`x` 向右；外力/反力向上为正；左截面正剪力向上；正弯矩为下缘受拉；`θ=dv/dx` 逆时针为正；`v` 向上为正。
- **容差**：力 `1×10⁻³ N`、弯矩 `1 N·mm`、转角 `1×10⁻⁹ rad`、挠度 `1×10⁻⁶ mm` 或相对误差 `1×10⁻⁶`（取较大者）；极值位置 `0.01 mm`；平衡残差 `|ΣF|≤1×10⁻⁶ N`、`|ΣM|≤1 N·mm`。
- **边界/备注**：`V` 在 `x=400 mm` 向下跳 `10000 N`；`M/θ/v` 连续；各分段曲线按解析式检查。
- **填写状态**：已确认（三轮复算）。
