# P3 板壳力学验收算例表（草稿，待用户填写）

> 用途：由力学/验收负责人独立提供 P3 真值、容差和工程判断。范围确认前只填写已选中的模块与工况。
>
> 禁止：不得运行待验收程序后反填预期值；不得把“与程序输出一致”当成来源。
>
> 证据要求：每个关键结果最终至少同时满足“用户验收真值”和“独立公开闭式解/成熟工具”。用户真值可来自手算、已验证工具或公开来源，但需写清方法、坐标和符号转换。禁止要求开发端读取用户本地参考书/PDF。

## 一、填写说明

每个算例必须填写：

1. 公式/工况标识：理论、边界、载荷、端部状态。
2. 全部输入：数值、单位、方向和坐标。
3. 预期输出：数值、单位、位置/表面/方向。
4. 容差：相对容差、绝对容差；零附近优先使用绝对容差。
5. 工程判断：应成功、应警告、应禁止，及预期提示要点。
6. 独立依据：计算方法或公开来源；如符号不同，写转换。
7. 审核状态：填写人、复核人、日期。

通用状态：

- [x] 草稿；尚无用户真值，不得进入实现
- [ ] 已填写真值，等待复核
- [ ] 已复核，可转为 `qa/fixtures/p3-*.json`

## 十、公共交互与单位验收

### [ ] P3-COM-01：跨单位等价

同一物理问题至少使用两套单位输入；预期物理结果等价。列出原始输入、换算输入、结果单位和容差。

### [ ] P3-COM-02：边界条件未选择

每个首版计算器至少执行一次：边界字段为空 → 计算按钮禁用或求解被拒绝 → 页面明确指出必须选择的边界，不保留旧成功结果。

### [ ] P3-COM-03：非有限数

至少覆盖 `NaN`、`Infinity` 或导致非有限中间量的输入；预期禁止成功结果，不显示 `NaN/Infinity`。
