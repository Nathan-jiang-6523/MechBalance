## 三、薄壁圆筒（中面半径；忽略 `O(t/r)` 径向应力）

公开闭式依据：膜理论平衡 `σθ=pr/t`；封闭端 `σz=pr/(2t)`、开口端 `σz=0`；薄壁圆管 `τzθ=T/(2πr²t)`，外轴力 `σN=N/(2πrt)`；平面应力 `σVM=sqrt(σθ²+σz²-σθσz+3τ²)`。

### [x] P3-TW-01：封闭端内压基准

- 工况/输入：封闭自由端；`r=1 m,t=0.01 m,pi=2 MPa,po=0`，`t/r=0.01,D/t=200`，无轴力/扭矩。
- 真值：中面 `σθ=200.000000 MPa`、`σz=100.000000 MPa`、`τzθ=0`；`von Mises=173.205081 MPa`、Tresca 等效应力 `200.000000 MPa`。非零相对容差 `1e-6`、绝对 `1 Pa`；零剪应力绝对 `1 Pa`。
- 状态：成功、无警告。独立代入：`2e6×1/0.01` 与其一半；端盖压力由筒壁轴向膜力平衡，径向应力不作为验收输出。

### [x] P3-TW-02：开口端内压

- 工况/输入：完全开口且无轴向约束/端盖；其余同 TW-01。
- 真值：`σθ=200.000000 MPa`、`σz=0`、`τzθ=0`、`von Mises=200.000000 MPa`；容差同 TW-01。
- 状态：成功、无警告；必须与封闭端的 `100 MPa` 轴向应力区分。依据：开口端无端盖压力合力，轴向膜力平衡为零。

### [x] P3-TW-03：外压导致符号反转

- 工况/输入：封闭端；`r=1 m,t=0.01 m,pi=0,po=2 MPa`，故 `p=-2 MPa`。
- 真值：`σθ=-200.000000 MPa`、`σz=-100.000000 MPa`、`von Mises=173.205081 MPa`；容差同 TW-01。
- 状态：成功、有强警告“仅计算膜应力，未校核外压失稳；不得据此判断结构安全”；外压幅值不得被解释成负输入。由 TW-01 线性反号，等效应力保持非负。

### [x] P3-TW-04：内压、轴力与扭矩组合

- 工况/输入：封闭端；`r=1 m,t=0.01 m,pi=1 MPa,po=0,N=+1.000 MN`（沿 `+z` 拉力），`T=+100.000 kN·m`（在 `+z` 截面产生 `+θ` 剪应力）。
- 真值：`σθ=100.000000 MPa`；`σz=50.000000+15.915494=65.915494 MPa`；`τzθ=1.591549 MPa`；`σVM=88.095982 MPa`。容差：相对 `1e-6`、绝对 `1 Pa`。
- 状态：成功、无警告。独立代入 `σN=N/(2πrt)`、`τ=T/(2πr²t)` 后按平面应力叠加；验收位置为远离载荷引入端的中面。

### [x] P3-TW-05：薄壁判据边界与超限

- 子输入 A（阈值）：`r=1 m,t=0.050000 m,pi=1 MPa,po=0`、封闭端，`t/r=0.05`。真值（仅作边界算法值）：`σθ=20.000000 MPa,σz=10.000000 MPa`；相对 `1e-6`、绝对 `1 Pa`。状态：成功、有提醒“恰处薄壁适用上限，建议 Lamé 解”。

- 依据：本表统一适用性门槛；上下界比较必须含等号，A 允许、B 拒绝。

### [x] P3-TW-06：非法几何与非有限数

- 输入/判定：分别提交 `(r,t)=(1,0) m`、`(0,0.01) m`、`r=1 m,t=NaN`（其余 `pi=1 MPa,po=0`）。三次均禁止计算，无数值真值/容差，不得保留旧结果或显示 `NaN/Infinity`。

## 四、Lamé 厚壁圆筒

公开闭式依据：`A=(pi ri²-po ro²)/(ro²-ri²)`，`B=ri²ro²(pi-po)/(ro²-ri²)`；`σr=A-B/r², σθ=A+B/r²`。封闭自由端 `σz=A`、`u=[(1-2ν)Ar+(1+ν)B/r]/E`；开口端 `σz=0,u=[(1-ν)Ar+(1+ν)B/r]/E`；平面应变 `σz=2νA,u=(1+ν)[(1-2ν)Ar+B/r]/E`。压力边界为 `σr(ri)=-pi,σr(ro)=-po`。

### [x] P3-LM-01：仅内压基准

- 输入：`ri=0.1 m,ro=0.2 m,pi=100 MPa,po=0`，封闭自由端；求值 `r=0.1,0.15,0.2 m`。
- 真值 `(σr,σθ,σz,u)`：`ri=(-100.000000,166.666667,33.333333 MPa,93.333333 μm)`；`0.15=(-25.925926,92.592593,33.333333 MPa,67.777778 μm)`；`ro=(0,66.666667,33.333333 MPa,56.666667 μm)`。
- 状态/容差：成功无警告；应力相对 `1e-6`/绝对 `1 Pa`，位移相对 `1e-6`/绝对 `1 nm`，零径向应力仅绝对 `1 Pa`。代入得 `A=33.333333 MPa,B=1.333333×10^6 Pa·m²`。

### [x] P3-LM-02：仅外压

- 输入：`ri=0.1 m,ro=0.2 m,pi=0,po=60 MPa`，封闭自由端；求值内外表面。
- 真值：`r=ri: (σr,σθ,σz,u)=(0,-160.000000,-80.000000 MPa,-68.000000 μm)`；`r=ro:(-60.000000,-100.000000,-80.000000 MPa,-58.000000 μm)`。
- 状态/容差：成功无警告；同 LM-01。独立量 `A=-80 MPa,B=-0.8×10^6 Pa·m²`，外压产生压应力与向内位移。

### [x] P3-LM-03：内外压同时作用

- 输入：`ri=0.1 m,ro=0.2 m,pi=100 MPa,po=20 MPa`，封闭自由端；求值 `r=0.1,0.15,0.2 m`。
- 真值 `(σr,σθ,σz,u)`：`ri=(-100.000000,113.333333,6.666667 MPa,70.666667 μm)`；`0.15=(-40.740741,54.074074,6.666667 MPa,48.222222 μm)`；`ro=(-20.000000,33.333333,6.666667 MPa,37.333333 μm)`。
- 状态/容差：成功无警告；同 LM-01。`A=6.666667 MPa,B=1.066666667×10^6 Pa·m²`。

### [x] P3-LM-04：开口、封闭与平面应变轴向边界

- 输入：沿用 LM-01，验收 `r=0.15 m`；分别选择开口自由端、封闭自由端、`εz=0` 平面应变。
- 共同真值：`σr=-25.925926 MPa,σθ=92.592593 MPa`。开口：`σz=0,u=75.277778 μm`；封闭：`σz=33.333333 MPa,u=67.777778 μm`；平面应变：`σz=20.000000 MPa,u=70.777778 μm,εz=0`。
- 状态/容差：三者成功无警告；同 LM-01，`εz` 绝对 `1e-12`。轴向状态必须显式选择，不得互换公式。

### [x] P3-LM-05：压力边界恒等式

- 输入：`ri=0.1 m,ro=0.2 m,pi=80 MPa,po=30 MPa`，封闭自由端。
- 真值：`σr(ri)=-80.000000 MPa`、`σr(ro)=-30.000000 MPa`；辅助核对 `σθ(ri)=53.333333 MPa,σθ(ro)=3.333333 MPa,σz=-13.333333 MPa`。
- 状态/容差：成功无警告；压力边界绝对 `1 Pa`、相对 `1e-8`。代入 `A=-13.333333 MPa,B=0.666666667×10^6 Pa·m²` 可直接消元证明两恒等式。

### [x] P3-LM-06：薄壁极限对比

- 输入：`ri=0.99 m,ro=1.01 m`（`rmid=1 m,t=0.02 m`），`pi=1 MPa,po=0`，封闭端。
- 真值：Lamé `σθ(rmid)=49.497500 MPa,σz=A=24.502500 MPa`；薄壁 `σθ=50.000000 MPa,σz=25.000000 MPa`。以薄壁值为分母差异分别 `1.005000%`、`1.990000%`。
- 状态/容差：成功、有提醒“薄壁为近似”；Lamé 数值容差 `1e-6/1 Pa`，差异百分比绝对 `1e-4` 个百分点；验收上限分别 `≤1.01%`、`≤2.00%`。依据为上述 Lamé 式与膜平衡的独立极限对照。

### [x] P3-LM-07：零压与压力对调

- 子输入 A：`ri=0.1,ro=0.2 m,pi=po=0`，封闭端；真值所有 `σr,σθ,σz,u=0`，绝对容差同统一零值；成功无警告。
- 子输入 B：`pi=80 MPa,po=20 MPa`，`r=0.15 m`；真值 `(σr,σθ,σz,u)=(-35.555556,35.555556,0 MPa,34.666667 μm)`。对调为 `pi=20 MPa,po=80 MPa` 后真值 `(-64.444444,-135.555556,-100.000000 MPa,-64.666667 μm)`。
- 状态/容差：两组成功无警告；同 LM-01。依据为 Lamé 式线性代入，压力幅值本身仍非负。

### [x] P3-LM-08：非法半径与越界求值

- 输入/判定：分别提交 `ri=0,ro=0.2 m`；`ri=0.2,ro=0.2 m`；合法 `ri=0.1,ro=0.2 m` 但求值 `r=0.0999 m` 或 `0.2001 m`。均禁止计算、无数值输出。
- 错误要点：`ri>0`、`ro>ri`、`ri≤r≤ro`；不得夹取到边界或复用旧结果。依据为几何域与 Lamé 分母非零条件。

## 五、实心圆薄板（Kirchhoff–Love 小挠度）

共同输入除另说：`a=1 m,t=0.02 m,E=200 GPa,ν=0.3,q=10 kPa` 全面均布，`D=Et³/[12(1-ν²)]=146520.146520 N·m`，轴对称实心板；`r=0` 有限且 `w'(0)=0`。固支闭式 `w=q(a²-r²)²/(64D)`；相应 `Mr=q[(1+ν)a²-(3+ν)r²]/16`、`Mθ=q[(1+ν)a²-(1+3ν)r²]/16`。

### [x] P3-CP-01：周边固支、均布载荷基准

- 边界/真值：`r=a` 固支 `w=w'=0`；中心/最大 `w(0)=1.066406250 mm`。中心 `Mr=Mθ=812.500000 N·m/m`，正面 `σr=σθ=+12.187500 MPa`、反面反号；边缘 `Mr=-1250.000000,Mθ=-375.000000 N·m/m`，正面应力 `-18.750000,-5.625000 MPa`。
- 状态/容差：成功无警告；位移 `1e-6/1 nm`、板线弯矩 `1e-6/1e-3 N·m/m`、应力 `1e-6/1 Pa`。最大值位置 `r=0`，载荷/挠度均 `+z`。

### [x] P3-CP-02：中心对称与有限性

- 输入：同 CP-01，评价 `r=0` 及极限 `r→0`。
- 真值：`w(0)=1.066406250 mm,w'(0)=0,Qr(0)=0,Mr(0)-Mθ(0)=0`，且 `Mr=Mθ=812.5 N·m/m` 有限。
- 状态/容差：成功无警告；零斜率 `1e-9`、零剪力绝对 `1e-3 N/m`、零矩差绝对 `1e-3 N·m/m`，其余同 CP-01。由偶函数闭式及 `Qr=-D d(w''+w'/r)/dr=-qr/2` 得证。

### [x] P3-CP-03：固支周边恒等式

- 输入：同 CP-01，评价 `r=a=1 m`。
- 真值：`w(a)=0,w'(a)=0,Mr(a)=-1250.000000 N·m/m,Mθ(a)=-375.000000 N·m/m,Qr(a)=-5000.000000 N/m`；总剪力幅值 `2πa|Qr|=31.415927 kN=πa²q`。
- 状态/容差：成功无警告；零量按统一绝对容差，非零相对 `1e-6`。剪力负号表示外法向截面上的内力方向，与 `+z` 载荷平衡。

### [x] P3-CP-04：周边简支、均布载荷

- 真值：中心/最大 `w=4.347656250 mm`，中心 `Mr=Mθ=q(3+ν)a²/16=2062.500000 N·m/m`，正面双向应力 `30.937500 MPa`；边缘 `Mr=0,Mθ=q(1-ν)a²/8=875.000000 N·m/m`。
- 状态/容差：成功无警告；同 CP-01。公开闭式可由轴对称双调和通解施加两边界条件得到。

### [x] P3-CP-05：零载与载荷反号

- 状态/依据：成功无警告；线性板方程 `D∇⁴w=q` 的奇对称性。

## 七、板屈曲（理想弹性，仅 SSSS 闭式）

公开闭式依据：四边简支矩形板受 `x` 向均匀压缩膜力时，`Ncr(m,n)=π²D/a²·[m²+n²(a/b)²]²/m²`；取正整数最小值，`σcr=Ncr/t`。数值绝不代表含缺陷、塑性或残余应力的真实承载力。

### [x] P3-BP-01：SSSS 方板单向压缩基准

- 输入：`a=b=1 m,t=0.02 m,E=200 GPa,ν=0.3`，四边简支，`Nx>0` 沿 `x` 压缩，`Ny=Nxy=0`。
- 真值：控制模态 `(m,n)=(1,1)`、`k=4`；`Ncr=5.784383532 MN/m`、`σcr=289.219177 MPa`、全宽临界力 `Pcr=Ncr b=5.784383532 MN`。
- 状态/容差：成功、有强警告“理想弹性分岔值，不是实际极限承载力”；相对 `1e-6`，膜力绝对 `1e-3 N/m`、总力绝对 `1e-3 N`，应力绝对 `1 Pa`。

### [x] P3-BP-02：模态切换边界

- 输入：同 BP-01 但 `b=1 m`、改变 `a/b`。在 `a/b=sqrt(2)=1.414213562`，`(1,1)` 与 `(2,1)` 同值 `Ncr=6.507431473 MN/m`。
- 邻域真值：`a/b=1.400` 时 `N11=6.464343718<N21=6.551994836 MN/m`，控制 `m=1`；`a/b=1.420` 时 `N21=6.489837383<N11=6.525266675 MN/m`，控制 `m=2`。
- 状态/容差：成功、有强警告同 BP-01；数值默认闭式容差，切换等值差绝对 `1e-3 N/m`。对 `n=1` 的相邻模态 `(m,1)` 与 `(m+1,1)`，两式相等得切换条件 `a/b=sqrt(m(m+1))`。

### [x] P3-BP-03：边界或 `k` 不匹配

- 输入：`a=b=1 m,t=0.02 m`，边界选择“固支”，但请求使用 SSSS 的 `k=4`；另一次边界字段为空。
- 状态：两次均禁止计算，无临界值；错误须含“`k=4` 仅适用于四边简支单向均匀压缩”或“必须选择边界”。不得自动降级、猜测系数或保留旧结果。
- 依据：屈曲系数属于边界/载荷的特征值，不是可跨工况复用的材料常数。

### [x] P3-BP-04：零/拉伸/非法厚度

## 八、圆柱壳屈曲（理想经典薄壳）
