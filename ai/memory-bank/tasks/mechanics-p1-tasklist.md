# P1 材料力学 MVP 开发任务（v0.4 已确认）

## 规格摘要

**首款产品**：截面性质 + 简支/悬臂梁综合计算器。

**求解方法**：Euler–Bernoulli 梁四阶微分方程；奇异函数/Macaulay 或等价分段多项式；边界条件求积分常数。

**首款覆盖**：P1 第 1、4、5、6、7 项。其余功能包：轴向与温度、圆轴扭转、莫尔圆、弯扭组合、压杆稳定。

**任务粒度**：每项按单开发者约 30–60 分钟设计；复杂任务必须继续拆分，不允许用“完成整个求解器”作为单任务。

## A. 首款范围冻结

### [x] P1-A01：冻结首款截面形状
**描述**：首款只含矩形、空心矩形、实心圆、圆管；I/H、T 形后续开发；L 形、槽形、任意组合截面后置。
**验收标准**：每种截面有参数图、尺寸约束、输出属性列表。

### [x] P1-A02：冻结截面属性定义

**验收标准**：`Jp` 与 `Jt` 不混用；所有输出带轴和单位。
**责任**：双方。

### [x] P1-A03：冻结梁理论假设
**描述**：确认等截面、常 `E/I`、线弹性、小变形、Euler–Bernoulli 假定。
**验收标准**：首款包含项和排除项写入 UI 警告。
**责任**：用户确认；Codex 记录。

### [x] P1-A04：冻结支承与载荷范围
**描述**：简支梁、左右两种固定方向悬臂梁；点力、点矩、分段均布载荷及多载荷叠加。

### [x] P1-A05：冻结坐标及正负号约定
**描述**：定义 `x/q/V/M/θ/v/σ/τ` 方向和正号。
**验收标准**：同一约定用于公式、示意图、曲线、页面结果和测试。
**责任**：用户确认；Codex 实现。

### [x] P1-A06：冻结结果呈现范围
**描述**：结果只在 Web UI 中显示；不开发打印报告、PDF、Word、Excel或复制报告。
**验收标准**：用户无需离开当前页面即可查看输入、结论、极值、曲线、警告和公式定义。
**责任**：用户确认；Codex 实现。
