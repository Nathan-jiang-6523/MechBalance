# 力学快速计算工具箱总计划（v0.2 草案）

## 规格摘要

**产品**：最新版 Chrome 中离线运行、双击 HTML 或快捷方式即可使用的力学快速计算工具箱。

**路线**：P1 材料力学 → P2 结构力学 → P3 板壳力学 → P4 二维有限元与拓扑优化。

**当前开发阶段**：只细化 P1。P1 任务见 `ai/memory-bank/tasks/mechanics-p1-tasklist.md`。

**技术栈**：Vue 3、TypeScript、Vite、KaTeX、Apache ECharts、Web Worker、Vitest、Playwright。

**后端集成**：无 Laravel、Livewire、FluxUI、数据库或联网 API。

## 项目阶段门

### [ ] GATE-01：冻结 P1 范围
**描述**：确认 P1 十项、公共单位换算器、首款综合计算器、公式范围和验收算例。
**验收标准**：首款无关键待定输入、输出、符号或理论假设。
**责任**：双方。

### [ ] GATE-02：验收首款综合计算器
**描述**：验收截面性质、简支/悬臂梁、多载荷、应力、曲线、Web UI 结果和离线构建。
**验收标准**：参考算例、跨单位测试、断网测试和 Chrome UI 测试通过。
**责任**：双方。

### [ ] GATE-03：验收 P1 材料力学 MVP
**描述**：验收 P1 十项、公共单位换算器和统一发布包。
**验收标准**：每项有公式定义、假设、警告和用户验收算例；遗留项单独登记。
**责任**：双方。

### [ ] GATE-04：冻结 P2 规格
**描述**：首验含轴向自由度的等 `E/A/I` 1D 梁，再细化等属性单跨超静定梁、影响线、桁架、刚架；分段变属性、连续多跨、内部铰/端释放及机械接口整体后置。
**验收标准**：矩阵自由度、边界、单元类型、恢复量和基准问题定义完整。
**责任**：双方。

### [ ] GATE-05：验收 P2
**描述**：完成 P2 工程与软件回归。
**验收标准**：解析解或受控有限元基准通过；应力分布坐标、单位和适用范围清楚。
**责任**：双方。

### [ ] GATE-06：冻结 P3 规格
**描述**：逐个冻结矩形板、圆板、薄壁/厚壁圆筒、板壳屈曲问题。
**验收标准**：每个计算器必须显式选择边界条件；无静默近似边界。
**责任**：双方。

### [ ] GATE-07：验收 P3
**描述**：完成板壳公式定义、边界、适用范围和用户验收算例审计。
**验收标准**：错误或缺失边界不能计算；所有近似有明确警告。
**责任**：双方。

### [ ] GATE-08：冻结 P4 规格
**描述**：冻结 Q4、平面应力、线弹性、小变形、稀疏矩阵、SIMP、滤波、OC、体积分数及 MBB 基准。
**验收标准**：网格上限、收敛准则、停止原因、性能目标和概念设计免责声明完整。
**责任**：双方。

### [ ] GATE-09：验收 P4
**描述**：验证单元、整体刚度、边界、灵敏度、优化更新、进度取消和迭代历史。
**验收标准**：MBB 基准达到已冻结容限；结果固定标记“概念设计”。
**责任**：双方。

### [ ] GATE-10：总产品发布
**描述**：生成离线发布包、快捷方式、版本说明和内部 QA 记录。
**验收标准**：目标 Windows 机器无需安装；最新版 Chrome 断网可用；用户侧只暴露一个入口。
**责任**：Codex 构建；用户签收。

## 全局质量要求

- [ ] 公式、代码、测试通过公式 ID 追溯。
- [ ] 允许使用公开网页、在线资料/数据表/PDF和模型知识整理公式；不读取用户本地参考书/PDF；验收真值由用户提供。
- [ ] 计算内核与 UI 分离。
- [ ] 内部统一 SI；输入输出支持工程单位。
- [ ] 不显示 `NaN`、无穷大或静默错误。
- [ ] 跳变、边界、适用范围和近似必须显式处理。
- [ ] 所有命令不能有后台进程，不添加 `&`。
- [ ] 不编写启动服务器命令；默认开发服务器已运行。
- [ ] 必须做移动端适配。
- [ ] 正式离线包不得依赖 CDN、外图或联网字体。
- [ ] 包含 Playwright 截图测试：`./qa-playwright-capture.sh http://localhost:8000 public/qa-screenshots`。

## 范围控制

- 未通过当前阶段门，不启动下一阶段功能开发。
- P2–P4 只保留范围定义；不在 P1 期间提前实现。
- 首版不做账号、云同步、数据库、协作权限或自动更新。
- 工程近似、经验阈值和强度结论必须由力学负责人确认。
