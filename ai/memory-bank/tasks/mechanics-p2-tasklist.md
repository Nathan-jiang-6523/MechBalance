# P2 结构力学开发任务（v0.2，机械接口已后置）

## 规格摘要

**原始需求**：

> “分段梁、超静定梁。”
> “平面桁架、平面刚架矩阵刚度法及应力分布。”
> “影响线及移动载荷组合。”
> “技术门：先验证 1D 梁有限元，再开发影响线、桁架与框架。”

**技术栈**：Vue 3、TypeScript、Vite、Vitest、Playwright、KaTeX、Apache ECharts、`vite-plugin-singlefile`；纯计算放 `src/core/structural/`，UI 放 `src/features/structural/`；复用 P1 单位与结果契约。

**交付形态**：完全离线单 HTML；最新版 Chrome 双击使用；无 CDN、后台、账号、数据库。

**目标时间线**：规格未冻结工期。确认范围与验收真值后再估算；不在本任务表提前承诺。

**当前冻结范围**：等 `E/A/I` 的单跨梁与单跨超静定梁（两端固支、固定—简支）、2D 桁架、2D 刚架、简支梁影响线和单轴组移动载荷。分段变 `E/A/I`、连续多跨梁、内部铰/端释放、机械接口后置。

**当前门禁**：`p2-confirmation-form.md` 已完成，`p2-acceptance-cases-form.md` 已冻结 42 个算例；可进入 Gate P2-0。仍须先通过 Gate P2-1 梁有限元解析对照，才可启动后续模块/UI。

**任务粒度**：每项按单开发者 30–60 分钟；若实测超时，继续拆分后再开发。
