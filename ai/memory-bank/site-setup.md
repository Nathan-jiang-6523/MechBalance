# 力学快速计算工具箱规格（v0.5 已确认）

## 1. 原始需求

> “将常用的材料力学的结论、二级公式、结构力学的知识如影响线、板壳力学的常用公式、二维拓扑优化程序等，做成各种快速计算的计算器（最好是在 html 能全部完成）。”

> “给工程师的是一个不需要额外安装的，双击 html 文件或者其他快捷方式，即可在最新的 Chrome 里打开的 WEB UI 界面的这种力学工具计算器。”

> “可在后台打包好，但是暴露给机械结构工程师的只有一个快捷方式。”

## 2. 产品目标

- 面向机械结构工程师，输入工程参数后快速得到可读结论。
- 隐藏公式推导、矩阵运算、有限元离散等实现细节。
- 完全离线运行；目标电脑只需最新版 Chrome，无需另装运行时。
- 按 P1–P4 递进开发；当前只冻结并实施 P1 材料力学 MVP。

## 3. 推荐技术栈

| 层级 | 选择 | 用途 |
| --- | --- | --- |
| UI | Vue 3 + TypeScript | 组件化表单、结果卡片、模块导航；类型约束输入输出 |
| 构建 | Vite | 开发构建、静态资源打包、生产压缩 |
| 样式 | CSS Variables + Vue Scoped CSS | 自建轻量工程 UI；不引入重型组件库 |
| 公式显示 | KaTeX（本地打包） | 显示公式、符号与适用条件；禁止 CDN |
| 曲线与云图 | Apache ECharts（按需引入） | 梁图、影响线、收敛曲线、拓扑密度云图 |
| 普通计算 | TypeScript 纯函数 | 材料力学、结构力学、板壳闭式解 |
| 重计算 | Web Worker + TypedArray | 拓扑优化迭代不阻塞 UI |
| 性能升级 | Rust/WebAssembly（按基准测试决定） | 仅在 TypeScript 拓扑优化达不到性能目标时启用 |
| 单元测试 | Vitest | 公式、量纲、边界和用户验收算例回归 |
| UI/截图测试 | Playwright | 最新 Chrome/Chromium 的交互和视觉回归 |
| 发布 | 单文件 `index.html` 优先 | 所有 JS、CSS、字体和 Worker 内联；双击打开 |
| 备用发布 | 隐藏资源目录 + Windows `.lnk` | 仅当单 HTML 体积或 WASM 加载不合适时采用；用户仍只见快捷方式 |

### 明确不采用

- Laravel / Livewire / FluxUI：需要服务端，不符合纯离线双击运行。
- Electron：包体与维护成本过高，且不是在 Chrome 中打开。
- Python 本地服务：目标电脑无法保证已装 Python。
- 在线 CDN、云端 API、账号系统、数据库：首版无需求，离线可用性优先。

## 4. 交付原则

- 每个计算器使用统一结构：输入、单位、示意图、计算、结果、适用范围、警告、依据、测试算例。
- 所有结果显示单位；内部统一转为 SI 基准单位计算。
- 输入必须有范围、符号和单位校验；不允许 `NaN`、无穷大或静默错误。
- 结果区先给工程结论，再按需展开公式和中间量。
- 每条公式必须登记公式 ID、表达式、符号约定、假设、边界条件、单位和版本。
- Codex 可使用公开网页、在线资料/数据表/PDF和模型知识整理力学公式；禁止打开用户本地参考书/PDF。
- 用户确认的坐标、正负号和 48 个验收算例具有最终验收优先级；公式与算例冲突时停止实现并由用户裁决。
- 计算内核与 UI 分离，避免改页面时破坏公式。

## 5. 产品路线图

### P1：材料力学 MVP

首批十项：

1. 常用截面性质：`A`、形心、`I`、`W`、`J`。
2. 轴向拉压、伸长、温度变形。
3. 圆轴扭转、扭转角、功率—转矩—转速。
4. 简支梁：集中力、均布载荷、集中力矩。
5. 悬臂梁：端力、均布载荷、端矩。
6. 梁多载荷叠加及剪力、弯矩、转角、挠度图。
7. 梁弯曲正应力、剪应力。
8. 弯扭组合、主应力、von Mises、Tresca。
9. 欧拉压杆稳定及长细比判断。
10. 平面应力莫尔圆。

P1 公共工具：常用单位换算计算器。它不计入十个材料力学计算器，但与首款综合计算器一起交付。

推荐完成顺序：首款综合计算器 → 轴向拉压/温度 → 圆轴扭转 → 莫尔圆 → 弯扭组合 → 压杆稳定。莫尔圆内核先于组合应力，可复用应力变换与主应力计算。

### P2：机械接口与结构力学

- 螺栓组受力与预紧初算。
- 焊缝组强度初算。
- 分段梁、超静定梁。
- 平面桁架、平面刚架矩阵刚度法及应力分布。
- 影响线及移动载荷组合。
- 技术门：先验证 1D 梁有限元，再开发影响线、桁架与框架。

### P3：板壳力学

- 矩形薄板：明确简支、固支边界。
- 圆板轴对称弯曲。
- 薄壁圆筒应力。
- 厚壁圆筒 Lamé 解。
- 板、壳屈曲初算。
- 所有板壳计算器强制选择边界条件；不允许静默套用近似边界。

### P4：二维有限元与拓扑优化

- Q4 单元，平面应力，线弹性，小变形。
- 稀疏刚度矩阵。
- SIMP 插值、灵敏度滤波、OC 更新、体积分数约束。
- MBB 梁基准。
- 进度、取消、迭代历史、停止原因。
- 结果固定标记“概念设计”；禁止将像素边界直接作为加工图或最终强度结论。

## 6. 首款产品：截面性质 + 简支/悬臂梁综合计算器

### 6.1 目标

一次验证单位系统、输入示意、反力、内力、应力、转角、挠度、极值、曲线及离线交付。

首款截面只覆盖：矩形、空心矩形、实心圆、圆管。I/H、T 形后续开发；L 形、槽形、任意组合截面继续后置。

### 6.2 梁求解底层

- 理论：Euler–Bernoulli 梁，线弹性、小变形、平截面假定。
- 控制方程：`EI·v''''(x)=q(x)`；符号正负由统一约定决定。
- 首版梁：等截面、常 `E`、常 `I`；分段 `EI` 延后至 P2。
- 载荷：任意位置集中力、集中力矩、分段均布载荷，可多载荷叠加；原始输入合计最多 10 项，按后台合并前计数。
- 实现：奇异函数/Macaulay 表达或等价分段多项式；由支承边界条件求积分常数。
- 输出场：反力、`V(x)`、`M(x)`、`θ(x)`、`v(x)`。
- 极值：端点、载荷/函数间断点、`V(x)=0`、`θ(x)=0` 等候选点统一求值，不只依赖绘图采样点。
- 应力恢复：使用截面性质计算弯曲正应力；剪应力仅对已支持截面使用明确公式。
- 集中力端点：简支梁仅允许 `0<a<L`；悬臂梁允许自由端集中力；固定端载荷归入支反力。
- 悬臂方向：左端固定和右端固定均支持；右端固定工况允许由左端固定验收算例按坐标镜像验证。

### 6.3 Web UI 结果最小内容

- 当前输入参数、单位、截面及梁载荷示意图。
- 理论假设、边界条件、符号约定、公式版本，可在页面内展开查看。
- 支反力、最大/最小内力、最大应力、最大转角、最大挠度及位置。
- 剪力、弯矩、转角、挠度曲线。
- 警告、适用范围、公式定义和计算器版本均在页面内显示。
- 不开发打印报告、PDF、Word、Excel、复制报告或报告模板。
- 页面输入在上、结果在下；先显示支反力摘要；两个图表槽位默认显示剪力图和弯矩图，可切换转角图和挠度图。
- 公式默认折叠，理论假设默认展开；无警告时警告区折叠，有活动警告/错误时自动展开。
- 第一次计算需点击按钮；首次成功后，合法输入修改采用约 300 ms 防抖自动重算。

## 7. 工程定义约束

- `I` 必须带轴：`Ix`、`Iy`；非对称截面还需 `Ixy`、主惯性轴。
- `W` 必须区分轴和正负边缘：不能只输出一个无方向 `W`。
- `Jp=Ix+Iy` 是极惯性矩；`Jt` 是 Saint-Venant 扭转常数。非圆截面不得混用。
- 梁的载荷、剪力、弯矩、转角、挠度必须共享同一坐标与正负号约定。
- 集中力使剪力跳变；集中力矩使弯矩跳变。绘图和极值搜索必须保留跳变左右值。
- P1 梁不包含剪切变形、塑性、大变形、动力、疲劳、接触。
- 跨高比 `L/h<10` 时强警告但仍计算；`h` 为弯曲方向截面总高度。
- `|v|max/L>1%` 时强警告但仍计算。
- 梁剪应力首款只支持实心矩形；空心矩形、实心圆、圆管显示“暂不支持”并禁用该结果。

## 8. 单位体系与换算器

- 每个输入字段显示当前单位，并允许从该物理量的合法单位中选择。
- 单位下拉只显示量纲相容选项；禁止自由输入单位字符串。
- 工程单位预设放在首位，SI 预设放在后位；切换预设只改变显示/输入单位，不改变物理问题。
- 默认工程预设冻结为一致单位制 `t–mm–s–N–MPa`：质量 `t`、长度 `mm`、时间 `s`、力 `N`、应力/压力/弹性模量 `MPa`。
- 默认派生单位：力矩/转矩 `N·mm`、线载荷 `N/mm`、截面模量 `mm³`、截面二次矩 `mm⁴`、密度 `t/mm³`。
- `t` 只表示质量吨，不表示力；吨力若以后加入，必须使用独立符号 `tf` 和力换算关系。
- 内核统一使用 SI 基准量计算，输入先归一化，结果再转换到选定显示单位。
- 输入区持续显示单位；计算前执行缺失单位、量纲和数量级检查。
- 单位换算器首版覆盖：长度、面积、体积、截面模量、截面二次矩、力、质量、应力/压力、弹性模量、力矩/转矩、线载荷、密度、温度/温差、角度、功率、转速。
- 换算器与计算内核共用同一转换表和测试，禁止维护两套换算常数。
- 单位下拉顺序：长度 `mm,m,cm`；面积 `mm²,cm²,m²`；力 `N,kN`；力矩 `N·mm,N·m,kN·m`；线载荷 `N/mm,kN/m,N/m`；应力/弹性模量 `MPa,GPa,Pa`；转角 `rad,°`；截面模量 `mm³,cm³,m³`；截面二次矩 `mm⁴,cm⁴,m⁴`；质量 `t,kg,g`；密度 `t/mm³,kg/m³,g/cm³`。
- 切换字段单位时清空原输入，要求用户重填；不静默改写现有值。

### 8.1 数值显示与曲线

- 普通值显示小数后 3 位；非零值若会显示为零或 `|x|≥1e6`，改用 6 位有效数字科学计数法。
- 极值位置显示小数后 2 位；曲线悬浮值显示 6 位有效数字。
- 内部保持完整精度，显示舍入不参与计算。
- 曲线使用自适应采样和 401 个基础采样点；强制加入端点、载荷点、跳变左右点和解析极值点。

## 9. 任务分工

| 责任方 | 职责 | 交付物 |
| --- | --- | --- |
| 用户/力学负责人 | 冻结适用范围、符号约定、默认单位、警告阈值 | 工程规则、分歧裁决 |
| 用户/验收负责人 | 独立提供验收算例，确认允许误差，审核结果工程含义 | 每模块正常/边界/反例算例及预期结果 |
| Codex/产品与开发 | 公式检索与结构化、架构、计算内核、UI、单位换算器、测试、离线构建、快捷方式 | 公式登记、源码、测试、发布包、文档 |
| 双方共同 | 范围冻结、分歧处理、版本验收 | 决策记录、签收结果 |

原则：Codex 可用公开网络、在线数据表/PDF和模型知识整理公式，但不得打开用户本地参考书/PDF。公式与代码通过公式 ID、版本和用户验收算例追溯。分歧由用户裁决。

## 10. 已确认的材料预设

- AL6061-T6：`E=69000 MPa`、`ρ=2.70×10⁻⁹ t/mm³`，作为可编辑名义预设。
- SPCC：`E=205000 MPa`、`ρ=7.87×10⁻⁹ t/mm³`，作为通用钢可编辑名义预设；不宣称为 JIS 保证值。
- 删除 PBT+30GF；首版不提供各向异性复合材料预设。
- 材料预设记录资料来源和访问日期，始终允许用户手工覆盖。

## 11. 已确认的默认工程单位制

- `t` 表示质量吨。
- 默认一致单位制为 `t–mm–s–N–MPa`。
- UI 中工程预设排在 SI 预设前；各字段仍可选择同量纲的其他单位。
- 输入框、结果和曲线坐标轴必须持续显示单位。

- 不保存/导入用户算例，功能后置。
- 首屏默认示例使用 `BEAM-SS-P-01`。
- 单项验收算例容差优先；未单列时默认相对容差 `1×10⁻⁶`，极值位置绝对容差 `0.01 mm`，零附近优先使用绝对容差。

## 12. 初步时间线（单开发者）

- P1 公共底座：3–5 个工作日。
- 首款综合计算器：8–12 个工作日。
- 常用单位换算器：1–2 个工作日；与公共底座并行，不单独延长关键路径。
- P1 其余五个功能包：15–25 个工作日。
- P1 公式审计、离线发布和验收：3–5 个工作日。
- P1 合计：约 6–9 周；包含公式确认、两轮修改和发布验收，实际取决于参考算例反馈速度。
- P2–P4 在前一阶段验收后分别细化，不提前承诺工期。
