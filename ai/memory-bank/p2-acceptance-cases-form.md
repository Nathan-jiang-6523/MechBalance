# P2 验收算例与独立真值表（待用户填写）

> 用途：在实现前冻结输入、预期结果、容差和工程判断。
> 独立性：预期值必须来自手算、公开闭式解、用户认可的独立程序或试验数据；禁止用本项目输出反填。
> 门禁：确认表和本表未签字前，不开发 P2 求解器或 UI。

## 一、填写规则

每个算例必须包含：

- 唯一 ID、模块、目的和状态。
- 输入数值、单位、坐标/正负号、边界与载荷。
- 预期数值、单位、求值位置及间断点的左/右侧。
- 相对容差、绝对容差；零附近优先绝对容差。
- 独立来源、版本/日期、计算过程或可复核附件说明。
- 预期警告或错误；非法模型不得只写“失败”。

来源类型：

- [ ] 用户手算
- [ ] 公开闭式解
- [ ] 独立结构分析程序
- [ ] 制造商/官方数据表
- [ ] 试验数据
- [ ] 其他：
