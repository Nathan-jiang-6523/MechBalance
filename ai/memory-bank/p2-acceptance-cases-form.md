# P2 验收算例与独立真值表

> 用途：冻结 P2 结构力学模块输入、预期结果、容差和错误行为。预期真值只来自本表所列闭式解、手算刚度法或独立程序，不得用项目输出反填。
> 统一日期：2026-07-19。数值计算使用未舍入值；表内显示值只为阅读。

## 一、统一约定与容差

- 单位制度：默认且首选 `t-mm-MPa-N-s`；第二备选为 `SI（kg-m-Pa-N-s）`。页面首次打开、重置模型及载入算例时均默认选中 `t-mm-MPa-N-s`。下文算例中明确写出的 `m/Pa/N·m` 数值保留为 SI 备选真值；在默认单位制度下必须按下表换算后输入、显示和验收，不得把 SI 数值原样套用到默认单位标签。

| 物理量 | 默认 `t-mm-MPa-N-s` | 备选 `SI（kg-m-Pa-N-s）` | 从默认值换算到 SI |
| --- | ---: | ---: | ---: |
| 质量 | `t` | `kg` | `×10³` |
| 长度、位移、坐标、极值位置 | `mm` | `m` | `×10⁻³` |
| 面积 | `mm²` | `m²` | `×10⁻⁶` |
| 截面二次矩/极惯性 | `mm⁴` | `m⁴` | `×10⁻¹²` |
| 弹性模量、应力 | `MPa=N/mm²` | `Pa=N/m²` | `×10⁶` |
| 力 | `N` | `N` | `×1` |
| 力矩 | `N·mm` | `N·m` | `×10⁻³` |
| 线荷载 | `N/mm` | `N/m` | `×10³` |
| 平移刚度 | `N/mm` | `N/m` | `×10³` |
| 平移—转动耦合刚度 | `N` | `N` | `×1` |
| 转动刚度 | `N·mm` | `N·m` | `×10⁻³` |
| 质量密度 | `t/mm³` | `kg/m³` | `×10¹²` |
| 时间、转角 | `s/rad` | `s/rad` | `×1` |

- 单位制度控件：输入区顶部提供可操作的 `单位制` 按钮组，选项固定为 `t-mm-MPa-N-s` 与 `SI（kg-m-Pa-N-s）`；当前选项必须有可见选中态。用户填写前、填写中和求解后均可切换。切换必须原子转换全部输入值、结果、坐标、图形标注、表头单位及绝对容差；不能只替换单位后缀，不能混用两套单位，也不能清空用户已填值。往返切换不得重新求解或改变物理模型；未舍入内部量换算，显示舍入只在最后一步执行。
- 换算基准：BEAM-A01 在默认制输入为 `L=4000 mm,E=200000 MPa,I=8.0e6 mm⁴,P_y=-40000 N,x_P=2000 mm`，结果为 `v_mid=-33.3333333333 mm,M_mid=+40000000 N·mm,RAy=RBy=+20000 N`；切至 SI 后必须分别为 `4 m,2.0e11 Pa,8.0e-6 m⁴,-40000 N,2 m` 及 `-0.0333333333333 m,+40000 N·m,+20000 N`。切回默认制后恢复前述默认值。
- 全局坐标：`+x` 向右，`+y` 向上；节点转角和外加力矩 `+θ/+Mz` 为逆时针。梁挠度 `v` 沿 `+y`。
- 梁内力标量：`N>0` 为拉，`M>0` 为下缘受拉（下挠），`V=dM/dx`；因此在左侧微段的右截面上，`V>0` 的物理箭头指向 `-y`。间断点必须报告左、右极限。
- 桁架杆力：拉力为正。框架公共杆端力按局部轴 `i→j`，`localEndForces=f_eq-k_l d_l` 表示单元对节点的力；`localResistingForces=k_l d_l-f_eq` 表示 member resisting actions，二者互为相反数。节点平衡必须使用前者。
- 单项容差优先；无单项值时：位移/转角相对 `1e-6`，位移绝对 `1e-6 mm（=1e-9 m）`，转角绝对 `1e-9 rad`；力/弯矩相对 `1e-6`，力绝对 `1e-3 N`，弯矩绝对 `1 N·mm（=1e-3 N·m）`；应力相对 `1e-6`，绝对 `1e-6 MPa（=1 Pa）`；位置绝对 `1e-3 mm（=1e-6 m）`。切换单位制时绝对容差同步换算，相对容差不变。
- 零值只用绝对容差：位移 `1e-7 mm（=1e-10 m）`、转角 `1e-10 rad`、力 `1e-6 N`、弯矩 `1e-3 N·mm（=1e-6 N·m）`。全局力平衡残差 `≤1e-6 N`、力矩平衡残差 `≤1e-3 N·mm（=1e-6 N·m）`；刚度矩阵对称残差按物理等价值验收：平移项 `≤1e-9 N/mm（=1e-6 N/m）`、耦合项 `≤1e-6 N`、转动项 `≤1e-3 N·mm（=1e-6 N·m）`，不得把混合自由度矩阵写成单一量纲。
- 非法数值包含 `NaN`、`±Infinity`；校验顺序固定为：非有限 → 非正值 → 几何退化 → 刚度奇异。显示舍入不参与验收。

来源缩写：`EB` = Euler–Bernoulli 梁闭式解及 Hermite 梁单元公式；`DSM` = 线弹性直接刚度法；`VW` = 单位荷载/虚功法；`IL` = Müller–Breslau/静力影响线。所有公式均在对应卡中给出，可脱离项目复算。

公开交叉核对：2D 梁/框架单元采用 `E/A/I`、6 个自由度和局部均布载荷的接口与 [CALFEM `beam2e` 官方函数参考](https://calfem-for-python.readthedocs.io/en/latest/calfem_reference/#calfem.core.beam2e)一致；全跨及区间分布载荷的范围与 [OpenSees `eleLoad` 官方文档](https://opensees.github.io/OpenSeesDocumentation/user/manual/model/pattern/PlainPatternloadcommands/eleLoad.html)交叉核对；初应变语义与 [OpenSees `InitStrainMaterial` 文档](https://opensees.berkeley.edu/wiki/index.php?title=Initial_Strain_Material)交叉核对。具体数值仍由本表闭式式和手算矩阵独立给出，不使用项目输出。
