### P2-D06 坐标、正负号与端力

本节直接沿用 P1 已确认约定；公式、输入、示意图、曲线、结果表、端力表和测试不得使用另一套符号。

- [X] 全局坐标为右手系：`+x` 向右、`+y` 向上、`+z` 垂直屏幕向外。
- [X] 节点位移 `u/v` 分别沿 `+x/+y` 为正；梁挠度 `v>0` 向上。
- [X] 节点转角 `θ` 与外加节点弯矩 `Mz` 绕 `+z` 为正，即屏幕内逆时针为正；`θ=dv/dx`。
- [X] 节点力 `Fx/Fy` 分别沿 `+x/+y` 为正；反力也按同一全局分量报告，不另设“支座正号”。
- [X] 载荷输入沿用 P1 的两种互斥模式：方向模式只接受非负幅值并由方向选择确定正负；符号模式直接读取带符号数并隐藏方向选择。不得同时叠加数值符号和方向符号。
- [X] 单元局部轴：`+x_l` 从节点 `i→j`，`+y_l` 为 `+x_l` 在平面内逆时针旋转 `90°`，`+z_l=+z`；局部自由度顺序固定为 `[u_i,v_i,θ_i,u_j,v_j,θ_j]`。

梁内力正号沿用 P1：

- 轴力 `N>0` 为拉力。
- 剪力 `V>0` 满足 `V=dM/dx`。在截面的负 `x_l` 面（左面）箭头沿 `+y_l`，在正 `x_l` 面（右面）箭头沿 `-y_l`；两面作用力互为反向。这就是 P1 的“左截面正剪力向上”。
- 弯矩 `M>0` 为正弯矩/下缘受拉；配合截面坐标 `y_l>0` 向上，正应力为 `σ_x=-M y_l/I`。在负 `x_l` 面正弯矩绕 `-z`，在正 `x_l` 面绕 `+z`。
- Euler–Bernoulli 梁关系固定为 `M=EI·d²v/dx²`、`V=dM/dx`。若分布载荷分量 `q_y` 按全局/局部 `+y` 为正，则 `dV/dx=q_y`。
- 集中节点力/移动力在 `x=a` 处满足 `V(a+)-V(a-)=Fy`；集中逆时针力矩满足 `M(a+)-M(a-)=-Mz`。跳变点必须同时报告 `a-` 与 `a+`，不得用单个采样值覆盖。

单元端力输出固定为：

- [X] 输出“单元作用于节点”的端力，不输出其相反量冒充同一字段。

- 局部端力向量顺序为 `[Fxi,Fyi,Mzi,Fxj,Fyj,Mzj]`；每个分量均按该端局部 `+x_l/+y_l/+z` 为正。全局端力由同一坐标变换得到，并明确标注 `local/global`。
- 取单元端部内侧极限时，端力与杆端内力映射为 `i+:[N,V,M]=[Fxi,-Fyi,Mzi]`，`j-:[N,V,M]=[-Fxj,Fyj,-Mzj]`；分布载荷作用下也必须按恢复后的端部极限满足该映射。节点平衡统一验收 `Σ(各单元作用于节点的端力)+外加节点力+支座反力=0`。

与 P1 的最小符号回归：简支梁受向下集中力时 `RA,RB>0`、载荷左侧 `V>0`、右侧 `V<0`、跨内正弯矩 `M>0`、下挠 `v<0`；左端固支悬臂受向下端力时 `Ry>0`、逆时针支座反力矩 `Mz>0`，梁内弯矩 `M<0`、`v<0`、自由端 `θ<0`。

是否要求同时显示局部轴和全局轴？

- [X] 局部分布载荷

冻结定义：

- 桁架温度只含杆件均匀温差 `ΔT`，自由热应变 `ε_T=αΔT`；不含截面温度梯度。
- 初应变为沿杆件局部 `+x_l` 的常量无应力应变 `ε_0`，正值表示自由伸长；弹性轴力统一按 `N=EA[(u_j^l-u_i^l)/L-(ε_T+ε_0)]`。
- 桁架自重按质量密度 `ρ`、截面积 `A`、杆长 `L`、可编辑重力加速度 `g` 计算；每根杆重量 `ρALg` 沿全局 `-y` 各半集中到两个端节点。首版不恢复杆件横向分布内力。
- 刚架分布载荷支持局部坐标下常值全跨载荷，以及区间 `[a,b]` 上常值局部分布载荷；`0≤a<b≤L`。三角形/梯形载荷后置。
- 刚架温度与初应变首版只产生均匀轴向自由应变；不含截面温度梯度、热弯曲或初曲率。
