## 一、来自规格的只读基线

以下内容已在项目规格中明确，不在本表扩展范围：

1. P2 包含“螺栓组受力与预紧初算、焊缝组强度初算、分段梁/超静定梁、平面桁架/平面刚架矩阵刚度法及应力或内力分布、影响线及移动载荷组合”。
2. 技术门为“先验证 1D 梁有限元，再开发影响线、桁架与框架”。
3. 生产交付为完全离线单 HTML；禁止 CDN、后台服务、账号和数据库。
4. 计算内核与 Vue UI 分离；内部统一 SI；复用 P1 单位、数值、校验、结果和警告契约。
5. P2 默认只做 2D；是否为 3D 预留数据字段仍需确认。
6. 用户验收真值独立于实现；真值冲突时停止对应模块并提交用户裁决。
