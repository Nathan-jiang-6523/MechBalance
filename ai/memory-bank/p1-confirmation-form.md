## 一、已确认项（只读摘要）

以下内容已冻结。本轮无需重复填写；需要变更时，请在文末“变更申请”中说明。

1. **交付形态**：完全离线 Web UI；目标电脑只需最新版 Chrome；双击 HTML 或快捷方式即可打开；不要求用户安装运行时。
2. **P1 范围**：10 个材料力学计算器，并交付独立的常用单位换算器。
3. **首款产品**：截面性质 + 简支/悬臂梁综合计算器；输出反力、内力、应力、转角、挠度、极值和曲线。
4. **首款截面**：只覆盖矩形、空心矩形、实心圆、圆管。I/H、T 形后续；L 形、槽形、任意组合截面继续后置。
5. **梁求解主线**：基于四阶梁方程，采用奇异函数/Macaulay 或等价分段多项式求解；支持多载荷叠加和间断点左右值。
6. **坐标及正负号**：沿用项目已约定的统一坐标和正负号；公式、示意图、曲线、结果和测试保持一致。
7. **默认一致单位制**：`t–mm–s–N–MPa`；其中 `t` 只表示质量吨，力使用 `N/kN`；吨力若以后加入必须写作 `tf`。
8. **默认派生单位**：力矩/转矩 `N·mm`、线载荷 `N/mm`、截面模量 `mm³`、截面二次矩 `mm⁴`、密度 `t/mm³`。
9. **单位交互**：工程单位预设优先，SI 预设后置；每个字段持续显示单位，并只允许选择量纲相容单位。
10. **结果载体**：结果只在 Web UI 内展示；不开发打印报告、PDF、Word、Excel、复制报告或报告模板。
11. **公式与验收边界**：Codex 可使用公开网页、在线资料/数据表/PDF和模型知识整理公式；禁止打开用户本地参考书/PDF。用户提供的正负号、验收算例、预期结果和容差具有验收优先级。
12. **P1 梁明确排除**：分段 `EI`、超静定梁、剪切变形、塑性、大变形、动力、疲劳和接触。
