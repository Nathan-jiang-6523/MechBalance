# P1 平面应力、莫尔圆与圆轴弯扭组合

版本：`P1-STRESS-PLANE-v1` / `P1-STRESS-BT-v1`

公式 ID：`STRESS-001`（平面应力/莫尔圆）、`STRESS-002`（von Mises/Tresca）、`STRESS-003`（圆轴弯扭恢复）。

## 范围与约定

- SI 内核：应力 Pa，长度 m，力矩 N·m；UI 默认 MPa、mm、N·mm。
- 拉应力为正。
- `τxy > 0`：正 x 面上的剪应力沿 +y。
- 物理坐标转角 `θ` 逆时针为正。
- 莫尔圆的剪应力轴向上；物理逆时针 `θ` 对应圆上顺时针 `2θ`。
- 平面应力第三分量固定为 `σz = τxz = τyz = 0`。

## 平面应力与莫尔圆

输入 `σx, σy, τxy`：

```text
C = (σx + σy) / 2
R = sqrt(((σx - σy) / 2)^2 + τxy^2)
σ1 = C + R
σ2 = C - R
θp = 1/2 atan2(2τxy, σx - σy)
τmax,in-plane = R
```

原始点采用：

```text
A = (σx,  τxy)
B = (σy, -τxy)
```

`A-B` 是直径。若 `R=0`，面内应力为等双轴状态，任意方向均为主方向；程序返回空角度，UI 显示“任意”，不输出 `NaN`。

## 三主应力与强度准则

将 `{σ1, σ2, 0}` 降序排列为 `{σI, σII, σIII}`：

```text
σVM = sqrt(((σI-σII)^2 + (σII-σIII)^2 + (σIII-σI)^2) / 2)
σTresca = max(|σI-σII|, |σII-σIII|, |σIII-σI|)
τmax,3D = σTresca / 2
```

输入正的许用/屈服强度 `S` 时：

```text
ηVM = σVM / S
ηTresca = σTresca / S
ηcontrol = max(ηVM, ηTresca)
```

`ηcontrol > 1` 标记超限。强度留空时只输出应力，不默认材料或强度。

## 实心圆与圆管弯扭组合

外径 `D`、内径 `d`；实心圆取 `d=0`：

```text
I = π(D^4-d^4) / 64
J = π(D^4-d^4) / 32 = 2I
c = D / 2
σb = M c / I
τt = T c / J
```

程序取一个“选定外缘控制点”：正 `M` 在该点产生正拉应力，正 `T` 产生正 `τxy`。恢复后将 `(σx, σy, τxy) = (σb, 0, τt)` 送入同一平面应力内核。

## 限制

- 线弹性、小变形、均匀圆截面。
- 不计缺口/键槽应力集中、残余应力、塑性、疲劳、屈曲及制造缺陷。
- 强度准则结果不是疲劳寿命或安全系数结论。
