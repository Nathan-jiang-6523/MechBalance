# P1 轴向拉压、伸长与温度变形

版本：`P1-AXIAL-THERMAL-v1`

公式 ID：`AXIAL-001`（应力/机械伸长）、`THERMAL-001`（自由温变）、`THERMAL-002`（完全约束兼容）。

## 范围

- 均匀直杆、分段串联直杆。
- 各段允许不同长度 `Lᵢ`、面积 `Aᵢ`、弹性模量 `Eᵢ`、线膨胀系数 `αᵢ` 和温差 `ΔTᵢ`。
- 一维同轴载荷、小变形、线弹性；各段参数在本段内均匀。
- 不包含自重、偏心、应力集中、连接局部变形、材料屈服和受压屈曲。

## 符号约定

- 轴向拉力、拉应力、伸长为正。
- 轴向压力、压应力、缩短为负。
- 升温为正，降温为负。
- 内部统一采用 SI：m、m²、N、Pa、K。

## 自由变形边界

串联各段传递同一轴力 `N`：

```text
σᵢ = N / Aᵢ
εᵢ,m = σᵢ / Eᵢ
ΔLₘ = Σ[N Lᵢ / (Eᵢ Aᵢ)]
ΔLₜ = Σ(αᵢ ΔTᵢ Lᵢ)
ΔL = ΔLₘ + ΔLₜ
```

自由边界允许外加轴力。温度变形不产生额外约束应力。

## 两端完全约束温变

完全约束必须由用户显式选择。此模式停用外加端力输入，按整体协调条件求共同约束内力 `Nᶜ`：

```text
ΣΔL = 0
C = Σ[Lᵢ / (Eᵢ Aᵢ)]
Nᶜ = -ΔLₜ / C
σᵢ = Nᶜ / Aᵢ
```

均匀杆退化为 `σ = -E α ΔT`。升温时结果为压应力，降温时结果为拉应力。

分段杆只要求总长度变化为零；各段自身变形一般不等于零，杆段界面可发生位移。

## 数值与界面约束

- `Lᵢ`、`Aᵢ`、`Eᵢ` 必须为有限正数，否则拒绝计算。
- `N`、`αᵢ`、`ΔTᵢ` 必须为有限数值；允许为零或负数。
- UI 默认 mm、N、MPa、`10⁻⁶/K`、`Δ°C`；单位修改后清空原值，防止旧数值被静默解释为新单位。
- 结果保留原始双精度数值；格式化只发生在显示层。
