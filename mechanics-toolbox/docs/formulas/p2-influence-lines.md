# P2 简支梁影响线与移动载荷公式

- 文档版本：`P2-IL-ML-v1.0.0`
- Gate：`P2-3`
- 冻结日期：`2026-07-19`
- 范围：简支梁、单轴组、单方向、静力包络

## 1. 坐标、单位与正负号

梁跨长 `L>0`，移动单位竖向荷载沿梁坐标 `z` 从左支座量起；梁外 `z<0` 或 `z>L` 的影响线纵坐标为零。截面位置为 `a∈[0,L]`。向下轴载以正绝对值 `P_i` 输入。

- 反力、剪力影响线：无量纲；轴载叠加结果为 `N`；
- 弯矩影响线：`m`；轴载叠加结果为 `N·m`；
- 位移影响线：`m/N`；轴载叠加结果为 `m`；
- 截面弯矩正值为下缘受拉；截面剪力采用冻结的左截面正面定义；位移沿全局 `+y` 为正，向下单位荷载产生负位移。

## 2. 单位荷载响应

左右支反力：

\[
\eta_{R_A}(z)=1-\frac zL,\qquad
\eta_{R_B}(z)=\frac zL.
\]

截面弯矩：

\[
\eta_M(z)=
\begin{cases}
z(L-a)/L,&z\le a,\\
a(L-z)/L,&z\ge a.
\end{cases}
\]

截面剪力：

\[
\eta_V(z)=
\begin{cases}
-z/L,&z<a,\\
(L-z)/L,&z>a.
\end{cases}
\]

荷载越过 `z=a` 时必须同时保留

\[
\eta_V(a^-)=-a/L,\qquad
\eta_V(a^+)=1-a/L,
\]

跳跃为 `+1`。荷载恰在任一支座时截面剪力纵坐标按冻结规则记为零。

指定位置 `a` 的位移影响线由 Maxwell–Betti 互等定理得到。令 `m=min(a,z)`、`n=max(a,z)`：

\[
\eta_v(z)=-\frac{m(L-n)\left[L^2-m^2-(L-n)^2\right]}{6LEI}.
\]

该式关于 `a/z` 对称，单位为 `m/N`。

## 3. 采样与关键点

结果序列合并用户采样点、`0/L`、响应截面及解析驻点。弯矩峰值显式保留 `z=a`；剪力在同一 `z=a` 生成 `left/right` 两点，不得用一条连续折线跨越跳变。位移影响线按 `z≤a`、`z≥a` 两段三次多项式求导，并只保留落在对应分段内的驻点。

## 4. 轴组位置与动态系数

轴组按行进方向以“前轴、其后各轴”排序。累计轴距

\[
s_0=0,\qquad s_i=\sum_{k=0}^{i-1}d_k.
\]

以前轴物理坐标 `z_f` 参数化：

\[
z_i=z_f-s_i\quad\text{（左到右）},\qquad
z_i=z_f+s_i\quad\text{（右到左）}.
\]

每轴先放大，再叠加：

\[
P_{i,eff}=\phi P_i,\qquad
R(z_f)=\sum_{0\le z_i\le L}P_{i,eff}\eta(z_i),
\]

其中 `φ` 必须有限且严格大于零；不得改变轴距、方向或控制位置。

## 5. 事件与极值搜索

候选事件由任一轴到达 `0`、`L`、截面位置或其他影响线分段点生成。反力、剪力、弯矩响应在每个事件区间内为线性函数；位移响应在每个区间内为三次函数，其导数为二次函数，直接求区间内实根。比较全部事件端点、剪力左右极限、解析驻点和轴组完全离桥状态，输出最大值、最小值、全部轴位置及控制轴。禁止用固定步长冒充极值。

位置容差不得大于 `1e-6 m`；冻结算例若规定更严容差则单项优先。首版车轴数上限 `100`，只允许单轴组、单方向，不含多车或多车道组合。
