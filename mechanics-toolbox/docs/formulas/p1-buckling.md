# P1 欧拉压杆与长细比公式登记

版本：`P1-BUCKLING-EULER-v1`

公式 ID：`BUCKLING-001`（回转半径/长细比）、`BUCKLING-002`（欧拉临界力与临界应力）。

- 回转半径：`i_x=sqrt(I_x/A)`，`i_y=sqrt(I_y/A)`。
- 有效长度：`L_e=K L`；两端铰支 `K=1`，固定-自由 `K=2`，两端固定 `K=0.5`，固定-铰支 `K=0.699`。
- 长细比：`lambda=L_e/i`，以较大长细比（较弱轴）控制。
- 欧拉临界力：`P_cr=pi^2 E I_min/L_e^2`。
- 欧拉临界应力：`sigma_cr=P_cr/A=pi^2 E/lambda^2`。

适用边界：理想直杆、轴心受压、线弹性、小挠度分岔。初弯曲、偏心、残余应力、材料屈服、局部屈曲及规范折减不在本公式内。

项目不内置通用“长杆”阈值。只有用户显式输入所采用规范/项目的 `lambda_lim` 时才输出阈值判断；否则只报告数值并标记“未判定”。
