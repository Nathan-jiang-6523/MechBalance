# P1 圆轴扭转与传动功率

版本：`P1-TORSION-POWER-v1`

公式 ID：`TORSION-001`（圆轴扭转）、`POWER-001`（功率—转矩—转速）。

## 坐标与符号

- 扭矩 `T` 为有符号量；正方向遵循轴线正向的右手定则。
- 剪应力 `τmax` 与扭转角 `θ` 保留 `T` 的符号。
- 转速 `n` 作为非负大小输入；旋转方向不由 `n` 的符号表示。
- 内核单位：`m`、`N`、`Pa`、`N·m`、`rad`、`W`、`r/s`。
- 默认界面单位：`mm`、`MPa`、`N·mm`、`°`、`kW`、`r/min`。

## 圆轴扭转

实心圆轴：

```text
Jt = π d⁴ / 32
```

圆管：

```text
Jt = π (D⁴ - d⁴) / 32
```

外表面最大剪应力与扭转角：

```text
τmax = T r / Jt
θ = T L / (G Jt)
```

材料弹性常数采用互斥输入：可直接输入剪切模量 `G`，也可输入杨氏模量 `E` 与泊松比 `ν`。对均匀各向同性线弹性材料：

```text
G = E / [2 (1 + ν)]
```

使用 `E + ν` 模式时要求 `E > 0` 且 `-1 < ν < 0.5`；未选中的输入组禁用且不参与计算。

适用范围：等截面、均匀各向同性、线弹性、小变形、Saint-Venant 扭转。结果不含台阶、键槽等局部应力集中，也不处理受约束翘曲。

## 功率—扭矩—转速

```text
ω = 2 π n
P = T ω
```

界面采用互斥模式：选定一个待求量，只读取另外两个已知量。

- 求 `P`：允许 `n = 0`，此时 `P = 0`。
- 求 `T`：`n = 0` 会造成除零，必须报错。
- 求 `n`：`T = 0` 会造成除零，必须报错；`P/T < 0` 会得到负转速，与非负转速约定冲突，必须报错。
- 未计入轴承、齿轮、联轴器等传动损失；输入功率不是自动修正后的电机额定功率。
