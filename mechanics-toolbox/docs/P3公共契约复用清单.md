# P3 公共契约复用清单

## 目标

P3 只新增板壳专属语义；单位换算、有限数、材料预设、通用字段校验、屏幕结果、公式引用和数学公式组件继续复用 P1。

## 复用映射

| P3 需求 | P1 能力 | 处理 |
| --- | --- | --- |
| SI 内部单位 | `src/core/units/converter.ts` | 直接复用 `normalizeToSI`、`convertFromSI` |
| 工程/SI 预设 | `src/core/units/catalog.ts` | 复用现有预设；全局切换另作 `integration:` 任务 |
| 有限数与负零 | `src/core/numeric/finite.ts` | 直接复用 |
| 数值显示 | `src/core/numeric/format.ts` | 直接复用，显示舍入不参与计算 |
| 安全算式 | `src/core/numeric/expression.ts` | UI 输入阶段复用 |
| 材料弹性模量 | `src/core/materials/` | 复用预设 `E`；P3 另要求显式 `ν` |
| 字段校验 | `src/core/validation/` | 复用数值、区间、大小关系和合并器 |
| 警告/错误 | `src/core/contracts/result.ts` | 复用 `ResultMessage` 与屏幕状态 |
| 公式引用 | `FormulaReference` | 复用 ID/版本；P3 另登记来源级别和解法性质 |
| 屏幕结果 | `ScreenResult` | P3 扩展控制位置、表面、方向和适用性 |
| 公式显示 | `src/components/MathFormula.vue` | 直接复用；已有横向滚动 |

## P3 专属扩展

- 显式边界联合类型；求解输入不允许 `undefined` 或隐含默认。
- 各向同性材料增加泊松比 `ν`，数学域固定 `-1 < ν < 0.5`。
- 结果控制信息固定包含位置、表面、方向、公式 ID 和解法性质。
- 适用性区分 `within`、`at-limit`、`warning`、`blocked`。
- 板线弯矩显示量 `N·m/m` 尚未进入共享单位目录；后续独立 `integration:` 提交。

## 禁止复制

- 不复制单位表、换算常数、材料预设或通用数值格式化器。
- 不在 Vue 组件内实现力学公式或适用性阈值。
- 不为 P3 修改 P1 文件名、目录结构或结果真值。
