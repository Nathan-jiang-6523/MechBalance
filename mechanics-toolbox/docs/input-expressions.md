# 数值输入算式

P1 数值输入框允许直接输入安全算式。算式先求值，再按输入框右侧所选单位进入 SI 内核。

## 支持语法

```text
+  -  *  /  ^  (  )  %
```

- 支持整数、小数、科学计数法和一元正负号。
- `^` 表示乘方，按右结合计算，例如 `2^3^2 = 512`。
- `%` 是后缀百分号，例如 `5% = 0.05`。
- 支持中文/全角的 `＋－×÷（）`。
- 运算优先级：括号、百分号、乘方、一元正负、乘除、加减。

## 示例

```text
0.6*100        = 60
100*(1-5%)     = 95
(20+30)/2      = 25
2.1e5          = 210000
```

输入 `0.6*100` 且单位选择 `N·mm` 时，程序采用的物理量是 `60 N·mm`，不是 `60 N·m`。算式中不得写单位，单位必须通过右侧选择框指定。

## 安全与限制

- 不使用 `eval` 或 `Function`；只解析上述数字和运算符。
- 不支持变量、函数、常量名、赋值或 JavaScript 语法。
- 除以零、括号不完整、非法字符、结果为 `NaN/Infinity` 时拒绝计算。
- 单个算式最长 256 个字符，括号最多嵌套 32 层。
